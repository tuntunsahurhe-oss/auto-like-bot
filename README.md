# Auto Like Telegram Bot

এই বোটটি প্রতিদিন ভোর ৫টায় অটোমেটিক লাইক পাঠায়।

### সেটআপ:
1. `bot.py` ফাইলে আপনার `TOKEN`, `ADMIN_IDS`, এবং `GROUP_ID` দিন।
2. `pip install -r requirements.txt` কমান্ড দিয়ে লাইব্রেরি ইন্সটল করুন।
3. বোটটি রান করুন: `python bot.py`

### বৈশিষ্ট্য:
- শুধুমাত্র এডমিন কমান্ড দিতে পারবে।
- শুধুমাত্র নির্দিষ্ট গ্রুপে এবং এডমিনের ইনবক্সে কাজ করবে।
- বাংলাদেশ সময় অনুযায়ী ভোর ৪:১০ এ API রিসেট এবং ৫:০০ টায় লাইক পাঠানো শুরু করবে।
- ১ মিনিট বিরতি দিয়ে প্রতিটি আইডিতে লাইক যাবে।
